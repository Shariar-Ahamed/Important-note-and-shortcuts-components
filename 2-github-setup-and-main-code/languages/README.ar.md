## 2 رمز الوصول الشخصي لـ GitHub (PAT)

| الخطوة | الشرح بالعربية |
|------|-------------|
| **Settings → Developer settings → Personal access tokens** | الانتقال لإنشاء رمز وصول شخصي جديد |
| تحديد الأذونات | حدد repo, notes, admin:org للاستخدام العام |
| رمز توضيحي | `ghp_yourPersonalAccessTokenHere...` |

---

### 2.1 إعداد المصادقة باستخدام مفتاح SSH

| الأمر | الشرح بالعربية |
|---------|-------------|
| `ssh-keygen -t ed25519 -C "your_email@example.com"` | إنشاء زوج مفاتيح SSH آمن |
| `eval "$(ssh-agent -s)"` | بدء تشغيل وكيل SSH في الطرفية |
| `ssh-add ~/.ssh/id_ed25519` | إضافة المفتاح الخاص إلى الوكيل |
| `cat ~/.ssh/id_ed25519.pub` | عرض المفتاح العام (نسخه إلى إعدادات GitHub) |
| `ssh -T git@github.com` | اختبار الاتصال بـ GitHub عبر SSH |
| `git remote set-url origin git@github.com:username/repo.git` | تحويل الرابط البعيد من HTTPS إلى SSH |

## 4 سير العمل الأساسي لـ Git

| الأمر | الشرح بالعربية |
|---------|-------------|

## 17 التراجع وتصحيح الأخطاء

| الأمر | الشرح بالعربية |
|---------|-------------|
| `git restore file.txt` | استعادة الملف إلى آخر حالة محفوظة |
| `git reset HEAD file.txt` | إلغاء تجهيز الملف |
| `git commit --amend` | تعديل رسالة أحدث تسليم |
| `git reset --soft HEAD~1` | إلغاء التسليم الأخير مع الإبقاء على الكود |
| `git reset --hard HEAD~1` | إلغاء التسليم الأخير وحذف التغييرات نهائياً |
| `git revert <commit-hash>` | تراجع عن تسليم بعينه بإنشاء تسليم عكسي |
